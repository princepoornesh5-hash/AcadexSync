ATTENDANCE SYSTEM
-------------------------------------------------

Faculty should be able to:

Select

• Date
• Class
• Section

View all students.

Mark each student as:

• Present
• Absent

Save attendance.

Faculty should also be able to edit attendance for that day.

-------------------------------------------------
ABSENCE REASON
-------------------------------------------------

If a student is marked absent,

the student can write a reason.

Example:

• Sick
• Medical
• Family Function
• Personal Work
• Others

There is NO approval workflow.

Faculty simply views the submitted reason.

The reason is attached to that attendance record.
