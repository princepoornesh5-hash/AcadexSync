# ACADEXSYNC — Render Production Startup Fix Report

**Date:** 2026-10-28  
**Repository:** `https://github.com/princepoornesh5-hash/AcadexSync`  
**Backend service name (Render):** `acadex-backend`  
**Production backend URL:** `https://acadex-backend-main.onrender.com`

---

## Executive Summary

The backend TypeScript build succeeded on Render, but startup crashed inside `validateProductionConfig()` in `Backend/dist/config/env.js`. Two independent root causes were identified and fixed:

1. **`CORS_ORIGIN: "*"` was hardcoded in `render.yaml`** — The production security validator correctly rejected wildcard CORS when `credentials: true` is set.
2. **JWT secrets were falling back to development defaults** — Render's `generateValue: true` generates secrets only the first time a service is created from a Blueprint; on subsequent redeploys or fresh manual deployments without dashboard variables set, Zod falls back to the compiled-in default strings (e.g. `acadex_development_jwt_secret_min_32_chars!`), which `validateProductionConfig()` correctly rejected.
3. **Build command in `render.yaml` excluded devDependencies** — `npm ci` without `--include=dev` omits TypeScript, causing build failure.

---

## 1. Root Cause — Confirmed From Code

### 1a. CORS_ORIGIN wildcard in render.yaml

**File:** `Backend/render.yaml` line 45–46 (before fix)

```yaml
- key: CORS_ORIGIN
  value: "*"
```

`app.ts` L58–80 builds `allowedOrigins` from `env.CORS_ORIGIN`. If `"*"`, `allowedOrigins = ['*']`. `validateProductionConfig()` in `env.ts` L209–211 catches this at startup and throws:

```
CORS_ORIGIN cannot be "*" (wildcard) in production when credentialed access is enabled
```

### 1b. JWT secrets falling back to development defaults

`env.ts` L22–26 defines Zod defaults:

```typescript
JWT_SECRET: z.string().default('acadex_development_jwt_secret_min_32_chars!'),
JWT_ACCESS_SECRET: z.string().default('acadex_development_access_token_secret_min_32_chars!'),
// ...etc.
```

`render.yaml` uses `generateValue: true` for all five secrets. Render only generates these values ONCE, when the service is first provisioned from the Blueprint. If missing from the dashboard, Zod resolves to the insecure development defaults. `validateProductionConfig()` L200–206 detected the exact strings and the `"development"` substring and threw for all five secrets.

### 1c. Build command missing devDependencies

Before fix in `render.yaml` line 8:
```yaml
buildCommand: npm ci && npm run build
```
`npm ci` without flags omits devDependencies. TypeScript (`tsc`) is a devDependency. Build fails with `tsc: command not found`.

Run this command five separate times (one per secret):
```bash
node -e "const c=require('crypto'); console.log(c.randomBytes(48).toString('hex'));"
```
This produces a 96-character hex string — well above the 32-character minimum and passes all production validators including the Render UUID-style check.

> **NEVER** paste secret values into chat, GitHub issues, docs, or source code.

## 4. CORS Configuration

### Architecture

`app.ts` L58–60 parses `CORS_ORIGIN` at startup:
```typescript
const allowedOrigins = env.CORS_ORIGIN === '*'
  ? ['*']
  : env.CORS_ORIGIN.split(',').map((o) => o.trim()).filter((o) => o.length > 0);
```

Development/test: any `localhost`/`127.0.0.1` port automatically allowed.  
Production: only origins in `allowedOrigins` permitted. Wildcard causes startup crash.

### Frontend origin determination

The Flutter Web frontend is deployed to Netlify. From `netlify.toml`:
```toml
command = "flutter build web --release --dart-define=API_BASE_URL=https://acadex-backend-main.onrender.com/api/v1"
```

**The Netlify site URL was NOT found in the repository.** No `*.netlify.app` domain or custom domain is hardcoded in any tracked source file.

> **The owner must supply the actual Netlify frontend URL.** Find it at https://app.netlify.com — open the ACADEXSYNC site → Site overview.

### CORS_ORIGIN format

Single origin:
```
CORS_ORIGIN=https://your-site-name.netlify.app
```

Multiple origins (comma-separated, no spaces):
```
CORS_ORIGIN=https://your-site-name.netlify.app,https://acadex.yourdomain.com
```
